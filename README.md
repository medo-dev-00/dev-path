# تحول لمبرمج 🚀

منصة تعليمية عربية تساعدك على تعلم البرمجة بطريقة منظمة من خلال **Roadmaps** ومسارات تعليمية ومجموعة مختارة من المصادر التعليمية العربية والإنجليزية.

الهدف من المشروع هو تجميع أفضل المصادر التعليمية في مكان واحد، وترتيبها في مسارات واضحة تساعدك تعرف **تبدأ منين، تتعلم إيه، وإيه الخطوة اللي بعدها**.

## 🗺️ Roadmaps

الـ Roadmap هي المسار الأساسي داخل المنصة.

كل مسار بيكون مقسم إلى مجموعة من المراحل والمواضيع، بحيث يقدر المتعلم يمشي في ترتيب منطقي بدل ما يتوه بين المصادر المختلفة.

### مثال

```text
Frontend Development
│
├── HTML
├── CSS
├── JavaScript
├── Git & GitHub
├── TypeScript
├── React
├── Next.js
├── Testing
└── Advanced Topics
```

وكل Topic يمكن أن يحتوي على مجموعة من المصادر التعليمية المناسبة له.

## 🔗 External Resources

المنصة لا تستضيف المحتوى التعليمي الخارجي، وإنما توفر روابط للوصول إلى المصادر الأصلية.

قد تحتوي الـ Roadmaps على روابط إلى:

* Official Documentation
* YouTube
* Educational Platforms
* Blogs
* Open Source Projects
* Developer Tools

عند فتح مصدر خارجي، ينتقل المستخدم إلى الموقع الأصلي وتطبق عليه سياسة الخصوصية وشروط الاستخدام الخاصة بذلك الموقع.

## 🚫 No Authentication

حاليًا المنصة لا تحتوي على:

* Registration
* Login
* User Accounts
* Passwords
* User Profiles

يمكن لأي شخص الوصول إلى المحتوى التعليمي مباشرة بدون إنشاء حساب.

---

## 📈 No Progress Tracking

لا تقوم المنصة حاليًا بتسجيل أو حفظ تقدم المستخدم.

بمعنى أن المنصة لا تقوم بحفظ:

* الدروس التي تم الانتهاء منها
* الـ Roadmaps التي بدأها المستخدم
* نسبة التقدم
* المواضيع التي قام المستخدم بدراستها

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/tahawwal-lmobarameg.git
```

### 2. Enter the project directory

```bash
cd tahawwal-lmobarameg
```

### 3. Install dependencies

```bash
npm install
```

أو:

```bash
pnpm install
```

أو:

```bash
yarn install
```

### 4. Run the development server

```bash
npm run dev
```

افتح:

```text
http://localhost:3000
```
